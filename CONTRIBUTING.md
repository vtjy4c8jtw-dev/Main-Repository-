# Contributing to Weather SuperComputer

Thank you for your interest in contributing! Here's how to get started.

## Setup

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Main-Repository-.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `npm run install-all`
5. Start development: `npm run dev`

## Development Workflow

1. Make your changes
2. Write/update tests
3. Commit with clear messages: `git commit -m "feat: add temperature aggregation"`
4. Push to your branch
5. Create a Pull Request

## Code Style

- Use ESLint and Prettier (configured in both frontend and backend)
- Follow existing code patterns
- Add comments for complex logic

## Commit Messages

Use conventional commits:
- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation
- `refactor:` for code improvements
- `test:` for tests

Example: `feat: add humidity aggregation from multiple sources`

## Pull Request Process

1. Update README.md with relevant changes
2. Ensure tests pass
3. Request review from maintainers
4. Address feedback

## Questions?

Open an issue or reach out to the maintainers.
